1. This repository is intended for:  

- The course instructor and TAs evaluating assignments via Gradescope.  
- Me. 

The data and code are for use in the cse3000 course at UConn.  

If this code or data were exposed to unintended users, the main risks are:

2. Data misuse and privacy concerns:  

- If given to other students of the course, they could copy my work which would be a violation of academic integrity.  
- If write access is compromised, unauthorized changes could alter scripts and inject malicious code. 
- Anonymous datasets can be reidentified and misused.

Overall risk is low.

3. Steps taken to secure repo:

- A `CODEOWNERS` file is configured.
- A `.gitignore` is configured to exclude local environment artifacts.
- No API keys or tokens are stored in this repository.

The `code_3000` repository that this is forked from is public and the controls reflect that.
